[1mdeploy[0m [38;5;246m2.4.0[0m
Ship a build to an environment

[1;38;5;208mUSAGE[0m
  deploy [38;5;246m[options][0m [38;5;246m<target>[0m [38;5;246m[files…][0m
  deploy rollback [38;5;246m[release][0m

  A target is a named environment from deploy.toml; files default to everything
  the build produced.

[1;38;5;208mCOMMANDS[0m
  [1mrollback[0m [38;5;246m[release][0m      Return to a previous release, the last one by default
  [1mstatus[0m                  Show what is live in each environment

[1;38;5;208mARGUMENTS[0m
  [38;5;246m<target>[0m                Environment to deploy to
  [38;5;246m[files…][0m                Files to include
